# איך מוציאים גרסה

המסמך מתאר את הצעדים מהרגע שגרסה מוכנה בענף `claude/1.2.x` ועד שהיא מופיעה באתר להורדה. הגרסה הנוכחית היא **1.2.3**.

## מה Claude עושה

1. מעדכן את מספר הגרסה בקובץ `desktop/package.json` ואת `CHANGELOG.md`.
2. מריץ את כל הבדיקות שכתובות ב־[CLAUDE.md](../CLAUDE.md):
   - בדיקות התוכן.
   - משחק מלא בלי מסך בשלוש בניות: הדף הרגיל, המהדורה התורנית וגרסת המחשב.
   - טעינה של שמירות מכל הגרסאות הקודמות.
3. בונה את שבעת הקבצים בעזרת `tools/pack-release.sh`. הסקריפט כותב לכל קובץ טביעת אצבע (sha256) לקובץ `SHA256SUMS.txt`.
4. מעביר את הקבצים למחשב של אבי, לתיקייה `Documents\reshet-hachaim-blender\installer`, ובודק שם את טביעת האצבע של כל קובץ.
5. דוחף את הענף ל־GitHub ופותח בקשת מיזוג (Pull Request) לענף `main`.
6. מכין את הטקסט לעמוד הגרסה. הטקסט של 1.2.3 נמצא בהמשך המסמך.

## מה אבי עושה

סשן של Claude לא יכול ליצור גרסה באתר ולא יכול להעלות קבצים גדולים, ולכן את השלבים האלה עושים ידנית:

1. נכנסים לבקשת המיזוג ב־GitHub ולוחצים "Merge pull request".
2. נכנסים לעמוד יצירת הגרסה: https://github.com/avifly123-maker/reshet-hachaim/releases/new?tag=v1.2.3&target=main&title=%D7%A8%D7%A9%D7%AA%20%D7%94%D7%97%D7%99%D7%99%D7%9D%201.2.3
   הקישור כבר ממלא את התג `v1.2.3`, את הענף `main` ואת הכותרת.
3. מדביקים בתיבת התיאור את הטקסט מהסעיף הבא.
4. גוררים לתחתית העמוד את שבעת הקבצים מהתיקייה `installer`.
5. מסמנים "Set as the latest release" ולוחצים "Publish release".

אחרי הפרסום הקישור [releases/latest](https://github.com/avifly123-maker/reshet-hachaim/releases/latest) מוביל לגרסה החדשה. הוא מופיע גם בקובץ README.

```

- כל בעלי החיים נבנו מחדש ברמת פירוט גבוהה: גוף אחד חלק, פרווה, נוצות וקשקשים בתבליט, ועיניים עם עפעף.

- כל משפחה מקבלת מבנה גוף משלה: חתוליים, כלביים, פרסתנים, מכרסמים ובעלי גוף כבד.

- צבע טבעי יותר: גב כהה, בטן בהירה, מעברים רכים ומרקם בכיוון השיער.
- תעופה: הכנף יורדת מהר ועולה כשהקצה שלה מקופל.

- דבורת הדבש ודבורת הסחלבים מבלנדר.

מק: מורידים את הקובץ שמתאים למחשב (apple-silicon לשבב של אפל, intel למעבד אינטל). ההוראות המלאות נמצאות בעמוד הראשי של הפרויקט.
```
